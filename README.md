# Data Analysis Using NumPy and Pandas

A beginner data analytics practice project demonstrating foundational data manipulation and analysis using Python, NumPy, and Pandas.

## Project Objective

The objective is to build practical familiarity with two core Python data-analysis libraries and understand how arrays, Series, and DataFrames can be used to inspect, manipulate, filter, and summarize data.

## Tools & Technologies

- Python
- NumPy
- Pandas
- Google Colab / Jupyter Notebook

## Skills Practiced

- Creating and working with NumPy arrays
- Array properties and numerical operations
- Indexing and slicing
- Pandas Series
- Pandas DataFrames
- Row and column selection
- Filtering data
- Updating values
- Basic aggregation and summary analysis

## Repository Contents

- `Python_DA_Assignment_1_Data_Analysis_using_NumPy_and_Pandas.ipynb` — hands-on analysis notebook

## Skills Demonstrated

`Python` • `NumPy` • `Pandas` • `Data Manipulation` • `Filtering` • `Basic Data Analysis`

## Learning Outcome

This project strengthened my understanding of the Python data-analysis workflow and provided the foundation for later projects involving data cleaning, exploratory data analysis, statistics, and visualization.
